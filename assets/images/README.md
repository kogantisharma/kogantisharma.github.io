# Image assets directory

Place the following images here before deploying:

| File | Dimensions | Usage |
|------|-----------|-------|
| `profile.jpg` | 200×200 px | Author sidebar avatar |
| `hero-bg.jpg` | 1920×600 px | Home page hero background |
| `og-image.png` | 1200×630 px | Open Graph / social share card |
| `teaser-default.png` | 500×300 px | Fallback teaser for posts/pages |
| `logo.png` | 100×100 px | Masthead logo (optional) |
| `rag-thumb.png` | 500×300 px | RAG project card teaser |
| `rag-career-banner.png` | 1920×500 px | RAG project page header |
| `mlops-thumb.png` | 500×300 px | MLOps pipeline project teaser |
| `platform-thumb.png` | 500×300 px | Cloud AI platform project teaser |
| `skills-banner.png` | 1200×400 px | Skills section on home page |

## Tips

- Use [Unsplash](https://unsplash.com) for free high-resolution photography
- Compress images with [Squoosh](https://squoosh.app) before committing (target: <200KB for teasers)
- Use WebP format where possible for better performance
